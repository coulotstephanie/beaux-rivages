# Sprint 18 — Application mobile

## Objectif

Offrir les parcours essentiels sur iOS et Android.

## Périmètre

- Carnet voyageur ;
- notifications push ;
- checklists opérationnelles ;
- photos ;
- mode hors connexion et synchronisation ;
- accessibilité mobile.

L’application consomme les mêmes contrats API que le web et n’embarque aucun
secret serveur.
