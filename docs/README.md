# Documentation Beaux Rivages

La documentation est organisée par responsabilité :

- [00_EXECUTIVE](./00_EXECUTIVE/README.md) — vision, stratégie et roadmap ;
- [01_PRODUCT](./01_PRODUCT/README.md) — produit, workflows et règles métier ;
- [02_BRAND](./02_BRAND/README.md) — marque et contenus ;
- [03_ARCHITECTURE](./03_ARCHITECTURE/README.md) — système, données et sécurité ;
- [04_ENGINEERING](./04_ENGINEERING/README.md) — pratiques de développement ;
- [05_OPERATIONS](./05_OPERATIONS/README.md) — exploitation et résilience ;
- [06_AI](./06_AI/README.md) — gouvernance et architecture IA ;
- [07_DESIGN](./07_DESIGN/README.md) — Design System, UX et accessibilité.

Pendant la convergence, les fichiers de référence historiques restent à la
racine afin de préserver les liens et les contrôles existants. Les pages de
chaque espace pointent vers une source canonique unique ou déclarent
explicitement un document à construire.
