## Corrections immédiates

Les libellés destinés aux voyageurs utilisent désormais « expériences »,
« attentions » ou « sélection » à la place d’« options » lorsque le terme était
commercial. Les identifiants techniques et contrats API restent inchangés pour
éviter une rupture.

## Prochaines étapes

1. formaliser les couleurs et typographies comme tokens nommés du Brand Book ;
2. créer un contrôle éditorial sur les chaînes publiques ;
3. centraliser les signatures et libellés récurrents ;
4. ajouter une checklist photo/vidéo avant publication ;
5. intégrer la revue de marque à la Definition of Done.
