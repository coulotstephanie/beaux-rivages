# Checklist de release

## Qualité

- [ ] PR approuvées et périmètres atomiques
- [ ] `npm run validate` vert
- [ ] E2E critiques verts
- [ ] Aucun secret ni donnée privée
- [ ] Alertes de dépendances examinées

## Produit

- [ ] Critères d’acceptation validés
- [ ] Recette desktop, tablette et mobile
- [ ] WCAG AA contrôlé
- [ ] Changelog et documentation à jour

## Données et exploitation

- [ ] Migrations sauvegardées et réversibles
- [ ] RLS et permissions testées
- [ ] Monitoring et alertes actifs
- [ ] Plan de retour arrière défini

## Déploiement

- [ ] Preview validée
- [ ] Production autorisée
- [ ] Smoke test après déploiement
- [ ] Version et décision consignées
