# ADR-0001 — Principes fondateurs

- **Statut :** Accepted
- **Date :** 2026-07-29

## Contexte

Beaux Rivages est conçu pour évoluer pendant de nombreuses années.

Les décisions techniques doivent privilégier :

- la stabilité ;
- l’évolutivité ;
- la lisibilité ;
- la documentation.

## Décision

Le projet adopte :

- Domain Driven Design ;
- Clean Architecture ;
- Feature First ;
- Repository Pattern ;
- Event Driven ;
- TypeScript Strict ;
- Documentation First.

## Conséquences

Tous les futurs développements doivent respecter ces principes.

Aucune exception n’est autorisée sans un nouvel ADR qui documente le contexte,
la décision, ses conséquences, son périmètre et, le cas échéant, sa durée.
