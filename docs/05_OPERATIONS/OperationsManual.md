# Operations Manual

Version : 1.0

Projet : Beaux Rivages

Classification : Portail public — contenu opérationnel exclu

Le manuel complet Beaux Rivages est confidentiel et n’est pas stocké dans ce
dépôt GitHub public.

## Périmètre

Le manuel privé couvre :

- la philosophie et l’organisation opérationnelles ;
- le cycle complet d’un séjour ;
- les arrivées autonomes et personnalisées ;
- les départs, le housekeeping et la maintenance ;
- le support voyageurs et la gestion des urgences ;
- la qualité, les indicateurs et les checklists ;
- la continuité d’activité et l’amélioration continue.

## Emplacement et accès

La source doit être conservée dans un espace documentaire privé avec :

- accès nominatif et moindre privilège ;
- historique des versions ;
- révocation des accès ;
- journal d’audit ;
- sauvegarde ;
- propriétaire métier identifié.

Le chemin local `docs-private/` est ignoré par Git comme filet de sécurité. Il
ne constitue pas une solution de partage ou de sauvegarde.

## Règles de publication

Ne doivent jamais être publiés dans ce dépôt :

- codes et procédures d’accès aux maisons ;
- coordonnées privées ou rotations d’astreinte ;
- détails exploitables des systèmes de sécurité ;
- données personnelles de voyageurs ou collaborateurs ;
- secrets, clés, mots de passe et liens privés ;
- procédures d’urgence dont la diffusion augmenterait le risque.

Une procédure peut disposer d’un résumé public uniquement après revue de
classification et suppression des informations sensibles.
