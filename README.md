# Beaux Rivages — v1.0

Site éditorial et de réservation directe de la marque d'hospitalité **Beaux Rivages**, développé avec Next.js 15.

## Version 1.0

- accueil immersif et destination-first ;
- pages du Chai des Tortues, de Villa Raie Manta et du Nid d'Été ;
- photographies authentiques des hébergements ;
- Carnet Beaux Rivages et carte concierge interactive ;
- personnalisation du séjour ;
- estimation et demande de réservation directe ;
- sitemap, robots.txt, page 404 et configuration Vercel ;
- interface responsive.

## Déploiement

Le projet complet doit être ajouté à ce dépôt, puis importé dans Vercel depuis la branche `main`.

Les disponibilités synchronisées, le paiement, la signature électronique et l'espace voyageur nécessitent des services externes.
