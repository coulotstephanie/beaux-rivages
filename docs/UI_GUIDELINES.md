# Principes d’interface

L’interface Beaux Rivages privilégie une hiérarchie calme, des contrastes WCAG AA, des cibles tactiles d’au moins 44 px et une navigation clavier complète.

Les écrans administratifs utilisent les mêmes conventions : en-tête, navigation secondaire, indicateurs, cartes, tableaux responsives, statut visible et message `role=status`. Les animations servent la compréhension et respectent `prefers-reduced-motion`.

Le prochain sprint de Design System devra extraire ces motifs en composants partagés sans réécriture visuelle.
