## Objet

Cette Release Candidate fige le périmètre actuellement candidat à la version
1.0. Elle est testable et documentée, mais n’est ni fusionnée, ni taguée, ni
autorisée en production.

La certification consolidée est disponible dans
[`CERTIFICATION_1.0.md`](../../CERTIFICATION_1.0.md).

Le numéro `1.0.0-rc.1` désigne la candidate de release. Le champ `version` du
package existant n’est pas modifié tant que la gouvernance des versions
techniques n’est pas formellement alignée.

## Périmètre candidat

- site public et pages des trois maisons ;
- moteur de réservation et disponibilité ;
- fondations Stripe TEST et paiements idempotents ;
- contrats et documents ;
- Back Office, Dashboard et authentification staff ;
- Revenue et Yield Management ;
- Carnet Beaux Rivages et CMS éditorial ;
- Channel Manager, Conciergerie, Housekeeping et Maintenance ;
- documentation produit, architecture, sécurité et exploitation.

Cette liste décrit le code présent dans la candidate. Elle ne constitue pas une
preuve de recette métier complète.

## Blocage P0

La procédure complète de sauvegarde et restauration n’a pas été démontrée.
Cette candidate reste donc **NO-GO**.

## Promotion vers v1.0.0

La promotion exige, dans cet ordre :

1. sauvegarde complète vérifiée ;
2. restauration réussie sur miroir ;
3. validation du Runbook et mesure RPO/RTO ;
4. application des trois migrations sur le miroir ;
5. recette complète et tests verts sur le commit exact ;
6. nouvelle décision Go/No-Go ;
7. fusion approuvée de la PR ;
8. migrations production avec plan de retour arrière ;
9. déploiement du commit validé ;
10. recette post-déploiement et surveillance renforcée ;
11. création du tag `v1.0.0` seulement après validation.

## Politique de gel

Jusqu’à la décision GO :

- aucune fonctionnalité nouvelle ;
- aucune migration distante ;
- aucune fusion ;
- aucun tag de release ;
- aucun déploiement production.

Toute correction indispensable crée `1.0.0-rc.2` avec un nouveau commit de
référence et une nouvelle exécution complète des contrôles.
