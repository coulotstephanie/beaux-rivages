# Product Book Beaux Rivages

Les documents sont normatifs et se lisent dans cet ordre :

1. [Vision produit](PRODUCT_BOOK_01_VISION.md) — pourquoi et pour qui la plateforme existe.
2. [Spécification UX](PRODUCT_BOOK_02_UX.md) — écrans, comportements et critères de recette.

En cas de contradiction, la Vision prime. Une spécification UX peut évoluer sans affaiblir la promesse de marque.
