# ADR-0008 — Documentation

- **Statut :** Accepted
- **Date :** 2026-07-29

## Décision

Toute Pull Request examine et met à jour :

- l’architecture ;
- la roadmap ;
- l’API ;
- la base de données ;
- les règles métier ;
- le changelog ;
- le Developer Handbook.

## Conséquences

Lorsqu’un document n’est pas affecté, la Pull Request le signale explicitement
comme « sans impact ». La documentation fait partie du changement, est relue
avec le code et ne peut pas être reportée après la mise en production.
